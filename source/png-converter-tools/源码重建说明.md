# PNG 转 JPG Web 源码重建版

本目录根据现有 4.16.0 EXE 的公开功能和配置重建了可维护的 Windows Forms 源码。当前源码重建版版本为 4.19.0，包含浅色科技风 UI 重构。

## 构建

需要 Windows 10/11 和 .NET 8 SDK：

```powershell
dotnet restore
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

## 已保留功能

- 文件/文件夹拖放和选择
- 子目录递归扫描 PNG
- 智能识别 1:1、1564:986、1464x600、1200x900、16:9
- 详情图、基础 A+、高级 A+、自定义尺寸配置兼容
- 透明图白底/黑底合成
- JPG 临时文件写入、格式和尺寸验证后原子替换
- 单张失败隔离、像素上限、日志和 CSV/JSON 报告
- 成功后询问是否删除 PNG

界面采用重构后的深色工作台风格，不要求与原 EXE 像素级一致。常用的输出预设、JPEG 质量、透明底颜色、选择文件、选择文件夹和取消处理都可以直接在窗口中操作；高级配置仍可通过“打开配置”编辑 `config.json`。

当前源码版使用内置 System.Drawing 转换。原 EXE 的 Photoshop 优先引擎属于可选增强，后续可以在 Windows 环境中接入 COM 适配器，而不改变默认内置引擎行为。

## 与原 EXE 的边界

原 EXE 没有附带 GUI 工程源码，因此无法保证窗口像素级一致，也无法从二进制可靠恢复所有内部实现。重建版优先保证公开说明中可观察到的处理结果、尺寸规则、容错和报告行为；原有 `run.ps1` + `photoshop_convert.jsx` 仍保留在仓库中，可作为 Photoshop COM 兼容路径。

## WSL 开发、Windows 测试

WSL 中可编辑和检查源码；构建、GUI、拖放、System.Drawing 和 Photoshop 测试应在 Windows x64 中执行。
